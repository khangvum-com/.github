# khangvum.com

A collaborative environment hosting **_infrastructure_**, **_homelab services_**, and **_configuration management_** for the **_`khangvum.lab`_** Active Directory domain.

## Overview

The **_`khangvum.com`_** organization powers an **_enterprise-grade hybrid homelab environment_** that bridges **_local infrastructure_** with **_secure public access_**.

- **_Centralized identity management_** powered by a **_local Active Directory_** **_`khangvum.com`_** domain.
- **_Secure edge connectivity_** providing public access to self-hosted applications via automated **_Cloudflare Tunnels_** without opening inbound ports.
- **_Unified access control_** integrating **_Authentik_** to federate local Active Directory accounts across public endpoints for **_Single Sign-On_** (**_SSO_**).
- **_Declarative system lifecycle management_** driving all infrastructure provisioning and service configurations through **_Infrastructure as Code_** (**_IaC_**).
